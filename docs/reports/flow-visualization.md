# Optical Flow Visualization Notes

This report stores representative optical flow visualizations used for supervisor review and demo storytelling.

## Recommended Captures

- Normal scene with smooth pedestrian movement.
- Congested scene with dense but non-panic movement.
- Anomalous/panic-like scene showing abrupt directional changes.

## Output Convention

- Save images under `docs/reports/figures/flow/`.
- Naming:
  - `normal_<video_id>_<frame_idx>.png`
  - `congestion_<video_id>_<frame_idx>.png`
  - `anomaly_<video_id>_<frame_idx>.png`

## Notes to Record Per Figure

- Camera/source ID
- Timestamp/frame index
- Brief interpretation of motion behavior
